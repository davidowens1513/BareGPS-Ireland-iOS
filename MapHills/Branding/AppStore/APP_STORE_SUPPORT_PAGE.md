# BareGPS Ireland Support Page

***Date: 30 October 2026. BareGPS Ireland version: 2.0.0 OpenBareMap version: 2.0.0***

Thank you for using BareGPS Ireland.

BareGPS Ireland helps you explore and log hills across Ireland, view your position and navigation information, and import, record and share GPX tracks. It also supports the optional OpenBareMap download for hiking-focused mapping without cellular or Wi-Fi coverage.

## What the app does

BareGPS Ireland includes features for:

- viewing and searching Irish hills;
- filtering hills and hill lists;
- marking hills as logged and exporting logged-hill information;
- showing live position, heading, elevation, distance, bearing and grid references;
- Go To navigation;
- importing, recording, saving, reopening and sharing GPX tracks;
- choosing online and offline map layers;
- downloading and using OpenBareMap; and
- choosing map details, units, colours and other settings.

## OpenBareMap

OpenBareMap is an optional companion map for BareGPS Ireland. It is an approximately 1 GB download and provides hiking-focused mapping without requiring cellular or Wi-Fi coverage after it has been installed.

OpenBareMap requires **BareGPS Ireland 2.0.0 or later**.

You can use BareGPS Ireland without installing OpenBareMap. Online map layers require a suitable network connection unless their data has already been cached by the map system.

### - Downloading OpenBareMap when first offered

When the OpenBareMap offer appears, choose:

- **Download Now** to open OpenBareMap management and begin the download process; or
- **Later** to continue without downloading it.

If you choose **Later**, OpenBareMap remains available from Settings. The first-launch offer is shown only for a limited number of launches.

### - Downloading OpenBareMap from Settings

1. Open **Settings** in BareGPS Ireland.
2. Find **OpenBareMap**.
3. Tap **Manage OpenBareMap**.
4. Wait while the app checks for the available download.
5. Tap **Download Map**.
6. Wait for downloading, verification and installation to finish.

When installation is complete, the OpenBareMap status is **Ready**. You can then select OpenBareMap from the app's map-layer list.

### - Wi-Fi and cellular data

**Wi-Fi Only** is on by default for OpenBareMap downloads.

With Wi-Fi Only turned on, the download waits for Wi-Fi and cannot use cellular data. To permit a cellular download, turn **Wi-Fi Only** off before starting the download.

The Wi-Fi Only setting cannot be changed while a map download is active. If necessary, cancel the active download, change the option and start again.

OpenBareMap is approximately 1 GB. Downloading over cellular data may use a significant part of your data allowance. The app does not download OpenBareMap over connections restricted by iOS Low Data Mode.

### - Waiting for Wi-Fi or a network

**Waiting for Wi-Fi** means that the download is waiting for an allowed Wi-Fi connection.

You can:

- connect the iPhone to Wi-Fi and allow the download to continue; or
- cancel the download, turn off **Wi-Fi Only**, and start the download again if you want to use cellular data.

**Waiting for Network** means that the download is waiting for a usable permitted connection.

### - Background downloading

OpenBareMap uses the iOS background-download system. The download can continue while BareGPS Ireland is not in the foreground, and iOS can relaunch the app to process completed download work.

iOS controls background scheduling. Network conditions, battery state and other system conditions can affect when work proceeds. Reopen **Manage OpenBareMap** to view the current status.

### - Cancelling a download

1. Open **Manage OpenBareMap** while the download is active.
2. Tap **Cancel Download**.
3. Confirm by tapping **Cancel Download** again.

Cancellation removes the temporary downloaded work files. If an older OpenBareMap version is already installed, cancellation does not remove that working version.

### - Download and installation statuses

The app may show the following statuses:

- **Not Installed** — OpenBareMap is not installed on this iPhone.
- **Checking for Download** — the app is checking the server for an available map.
- **Checking for Update** — the app is checking whether a newer map is available.
- **Ready to download** — a compatible map is available to download.
- **Waiting for Wi-Fi** — Wi-Fi Only is on and the download is waiting for Wi-Fi.
- **Waiting for Network** — the download is waiting for another usable permitted connection.
- **Downloading — n%** — the map files are being downloaded.
- **Verifying Download** — the app is checking the downloaded files.
- **Installing** — the verified map is being made ready for use.
- **Ready** — OpenBareMap is installed and available.
- **Update ready** — a newer compatible OpenBareMap version is available.
- **Fix needed** — an operation failed. Read **Last Error** and use **Try Again**.

There is no separate Repair function. **Try Again** repeats the server check; it does not selectively repair an installed map.

### - Updating OpenBareMap

1. Open **Manage OpenBareMap**.
2. Tap **Check for Update**.
3. If a newer map is available, the status changes to **Update ready** and an update offer appears.
4. Tap **Update Map** to begin, or **Later** to keep using the current map.
5. Wait for the new map to download, verify and install.

The current installed map remains available while its replacement is downloaded and checked. The replacement is activated only after verification and installation succeed.

### - If the status says Fix needed

1. Read the message shown under **Last Error**.
2. Check that the iPhone has a usable internet connection.
3. Check the Wi-Fi Only setting and the type of connection being used.
4. Check that the iPhone has enough free storage.
5. Tap **Try Again**.
6. If a download or update becomes available, tap **Download Map** or **Update Map**.

If an installed map appears damaged or does not work correctly, remove it and download it again. The app does not currently provide a separate repair command.

### - Removing OpenBareMap

1. Open **Settings** in BareGPS Ireland.
2. Find **OpenBareMap** and tap **Manage OpenBareMap**.
3. Tap **Remove Map**.
4. Confirm by tapping **Remove Map** again.

The app will use an online map until OpenBareMap is downloaded again. Removing OpenBareMap does not remove GPX files, logged hills or app settings.

### - Storage space

OpenBareMap downloads approximately 1 GB of map data. Additional temporary free space is needed while the map is being downloaded, checked and installed.

If the iPhone does not have enough free space, the app reports an error. Check available storage in:

**iPhone Settings > General > iPhone Storage**

Free some space, return to **Manage OpenBareMap**, and try again.

### - OpenBareMap display details

When OpenBareMap is selected, its display options allow you to show or hide:

- Hillshade;
- Land Cover;
- Boundaries;
- Minor Roads;
- Road Names;
- Railways and Stations;
- Ferry Routes;
- Cycling Routes;
- Hiking Routes;
- Island Names; and
- Water-Feature Names.
- Grid lines
- Townlands

Your choices are saved and are not reset by a map update.

## Location Access

BareGPS Ireland uses your iPhone's location services to:

- show your current position on the map;
- follow your movement as you walk;
- show your elevation and grid reference;
- calculate distance and bearing;
- support Go To navigation;
- use your current position for location-based hill lists; and
- record GPX tracks.

Location access is optional, but these features cannot work correctly without it.

### - Recommended iPhone settings

For normal use, we recommend:

- **Location Access: While Using the App**
- **Precise Location: On**

BareGPS Ireland does not need **Always** location access.

**While Using the App** allows BareGPS Ireland to use your position while you are using its map and navigation features. It also allows an active GPX recording to continue when the app is minimised or the iPhone screen is locked.

BareGPS Ireland enables background location use only while a GPX recording is active. When you stop the recording, the app stops requesting background location updates.

### - Choosing an option when first asked

When iOS first asks whether BareGPS Ireland may use your location, choose:

**Allow While Using App**

Depending on your iOS version, the prompt may instead offer:

- **Allow Once** — location works temporarily, but iOS may ask again later.
- **Allow While Using App** — recommended.
- **Don't Allow** — location-based features will not work.

If a **Precise Location** switch is shown, leave it turned on.

### - Why Precise Location should be on

With **Precise Location** on, BareGPS Ireland receives the best position available from the iPhone. This is important for:

- useful GPX track recording;
- accurate position display;
- grid references;
- distance and bearing calculations; and
- navigation while walking.

If Precise Location is off, iOS supplies only an approximate position. The displayed position may be a large distance from your real location, and GPX tracks, grid references, distance and bearing information may be inaccurate.

### - Changing the setting later

To review or change BareGPS Ireland's permission:

1. Open the iPhone **Settings** app.
2. Tap **Apps**.
3. Tap **BareGPS Ireland**.
4. Tap **Location**.
5. Choose **While Using the App**.
6. Turn **Precise Location** on.

On some iOS versions, the route may instead be:

1. Open **Settings**.
2. Tap **Privacy & Security**.
3. Tap **Location Services**.
4. Tap **BareGPS Ireland**.
5. Choose **While Using the App**.
6. Turn **Precise Location** on.

After changing the setting, return to BareGPS Ireland. It may take a short time for the iPhone to obtain a current position, particularly indoors or after Location Services has been off.

### - If no Location option appears

Check that Location Services is enabled for the whole iPhone:

1. Open **Settings**.
2. Tap **Privacy & Security**.
3. Tap **Location Services**.
4. Turn **Location Services** on.
5. Find **BareGPS Ireland** in the app list.
6. Choose **While Using the App**.
7. Turn **Precise Location** on.

If BareGPS Ireland has not yet requested permission, return to the app and tap a feature that needs your position, such as the current-position button, Go To navigation or GPX recording.

### - If location access was refused

If you previously chose **Don't Allow**, iOS may not show the permission question again. Change the permission manually in iPhone Settings using the steps above.

BareGPS Ireland cannot override an iOS permission or turn Location Services on for you.

### - GPX recording in the background

Start the GPX recording while BareGPS Ireland is open. Once recording has begun, it can continue while:

- you use another app;
- BareGPS Ireland is minimised; or
- the iPhone screen is locked.

iOS may show a location indicator while background recording is active. This is normal and indicates that the iPhone is supplying location updates.

For the most reliable recording:

- use **While Using the App** with **Precise Location** on;
- confirm that recording has started before locking the phone;
- do not force-quit BareGPS Ireland during the recording; and
- stop the recording in BareGPS Ireland when the walk is complete.

A GPX recording cannot continue if Location Services is turned off, BareGPS Ireland's permission is changed to **Never**, or the app is force-quit.

### - Location accuracy

Location accuracy depends on the iPhone, satellite visibility and local conditions. Accuracy can be reduced:

- indoors;
- under dense tree cover;
- beside cliffs or tall buildings;
- in deep valleys;
- when the iPhone has a poor satellite view; or
- when Precise Location is off.

BareGPS Ireland is a navigation aid. Always carry appropriate maps and equipment and use your own judgement, particularly in remote or hazardous terrain.

## Imported or saved GPX files are missing

Check the app's saved GPX area and any Files location used when importing, sharing or exporting the file. A file that was deleted from the app or Files may no longer be available.

If contacting support about a GPX problem, say whether the file was recorded by BareGPS Ireland or imported from another source. Do not send a GPX file containing sensitive location information unless it is necessary and you are comfortable sharing it.

## Online map tiles are not loading (OpenTopo / Satellite)

Possible causes include:

- no network connection;
- a weak or restricted connection;
- a temporary map-provider problem; or
- no cached coverage for the area being viewed.

Try another network or another map layer. OpenBareMap does not require a network after it is fully installed.

## Logged hills or settings appear to have reset

Logged hills and settings are stored locally on the iPhone. They may no longer be available if the app was removed, the iPhone was reset, local app data was cleared, or a backup containing the information was not restored.
